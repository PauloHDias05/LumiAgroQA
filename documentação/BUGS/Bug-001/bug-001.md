# BUG-001 - Sistema permite criar conta sem informar o nome

## Épico
Cadastro

## Caso de Teste Relacionado
CT-003 - Criar conta sem informar o nome

## Descrição
O sistema permite a criação de uma nova conta mesmo quando o campo "Nome" não é preenchido.

O campo deveria ser obrigatório e impedir o cadastro quando estiver vazio.

## Passos para Reproduzir

1. Acessar a página de cadastro.
2. Deixar o campo "Nome" vazio.
3. Informar um e-mail válido e ainda não cadastrado.
4. Informar uma senha válida.
5. Clicar no botão para criar a conta.

## Resultado Esperado
O sistema deve impedir a criação da conta e exibir a mensagem:

"Informe seu nome completo."

## Resultado Obtido
O sistema ignorou o campo "Nome" vazio e criou a conta normalmente.
