# CT-002 - Acessar checkout do plano mensal 1

## Épico
Planos

## Pré-condição
Usuário deve estar autenticado e na página de planos mensais.

## Cenário BDD

**Dado** que o usuário esteja visualizando os planos mensais

**Quando** selecionar o primeiro plano mensal

**Então** o sistema deve direcionar o usuário para o checkout do Stripe

## Resultado Esperado
O usuário deve ser redirecionado para uma página válida do checkout do Stripe.

## Resultado Obtido
O usuário foi redirecionado corretamente para a página de checkout do Stripe.
