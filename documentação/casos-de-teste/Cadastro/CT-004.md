# CT-004 - Criar conta com senha menor que 8 caracteres

## Épico
Cadastro

## Pré-condição
Usuário deve estar na página de cadastro.

## Cenário BDD

**Dado** que o usuário esteja na página de cadastro

**Quando** preencher o nome e o e-mail corretamente e informar uma senha com menos de 8 caracteres

**Então** o sistema deve impedir a criação da conta e informar o tamanho mínimo exigido para a senha

## Resultado Esperado
O sistema deve exibir a mensagem "A senha precisa ter ao menos 8 caracteres." e não deve criar a conta.

## Resultado Obtido
O sistema exibiu a mensagem correta e não criou a conta
