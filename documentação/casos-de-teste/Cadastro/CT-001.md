# CT-001 - Criar conta com sucesso

## Épico
Cadastro

## Pré-condição
Usuário deve estar na página inicial e possuir acesso à opção de criação de conta.

## Cenário BDD

**Dado** que o usuário acesse a página de cadastro

**Quando** preencher o nome, um e-mail válido e uma senha válida

**Então** o sistema deve criar a conta e direcionar o usuário para a página de assinatura

## Resultado Esperado
A conta deve ser criada com sucesso e o usuário deve ser direcionado para a página de assinatura.

## Resultado Obtido
A conta foi criada com sucesso e o usuário foi direcionado para a página de assinatura
