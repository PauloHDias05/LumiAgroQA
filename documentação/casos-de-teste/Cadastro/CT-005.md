# CT-005 - Criar conta com e-mail já cadastrado

## Épico
Cadastro

## Pré-condição
Deve existir uma conta previamente cadastrada com o e-mail utilizado no teste.

## Cenário BDD

**Dado** que o usuário esteja na página de cadastro

**Quando** preencher os dados utilizando um e-mail que já possui cadastro

**Então** o sistema deve impedir a criação de uma nova conta com o mesmo e-mail

## Resultado Esperado
O sistema deve exibir a mensagem "Este e-mail já está cadastrado." e não deve criar uma nova conta.

## Resultado Obtido
O sistema exibiu a mensagem correta e não criou a conta
