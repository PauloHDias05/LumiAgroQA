# CT-003 - Criar conta sem informar o nome

## Épico
Cadastro

## Pré-condição
Usuário deve estar na página de cadastro.

## Cenário BDD

**Dado** que o usuário esteja na página de cadastro

**Quando** preencher um e-mail válido e uma senha válida sem informar o nome

**Então** o sistema deve impedir a criação da conta e informar que o nome completo é obrigatório

## Resultado Esperado
O sistema deve exibir a mensagem "Informe seu nome completo." e não deve criar a conta.

## Resultado Obtido
O sistema ignorou o campo 'Nome' e criou a conta

## Status
REPROVADO

## Automatizado
SIM
