# CT-001 - Realizar login com e-mail inválido

## Épico
Login

## Pré-condição
Usuário deve estar na página de login.

## Cenário BDD

**Dado** que o usuário esteja na página de login

**Quando** informar um e-mail em formato inválido e uma senha válida

**Então** o sistema deve impedir o login e informar que o e-mail é inválido

## Resultado Esperado
O sistema deve exibir a mensagem "Informe um e-mail válido." e não deve realizar o login.

## Resultado Obtido
O sistema exibiu a mensagem correta e não realizou o login.
