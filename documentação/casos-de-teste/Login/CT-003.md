# CT-003 - Realizar login com senha menor que 8 caracteres

## Épico
Login

## Pré-condição
Usuário deve estar na página de login.

## Cenário BDD

**Dado** que o usuário esteja na página de login

**Quando** informar um e-mail válido e uma senha com menos de 8 caracteres

**Então** o sistema deve impedir o login e informar o tamanho mínimo exigido para a senha

## Resultado Esperado
O sistema deve exibir a mensagem "A senha precisa ter ao menos 8 caracteres." e não deve realizar o login.

## Resultado Obtido
O sistema exibiu a mensagem correta e não realizou o login.
