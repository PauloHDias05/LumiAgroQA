# CT-002 - Realizar login com senha inválida

## Épico
Login

## Pré-condição
Usuário deve possuir uma conta cadastrada e estar na página de login.

## Cenário BDD

**Dado** que o usuário esteja na página de login

**Quando** informar um e-mail cadastrado e uma senha incorreta

**Então** o sistema deve impedir a autenticação do usuário

## Resultado Esperado
O sistema deve exibir a mensagem "E-mail ou senha incorretos." e não deve realizar o login.

## Resultado Obtido
O sistema exibiu a mensagem correta e não realizou o login.
